# 📊 Purchase & Shopping Analysis Dashboard

## 📌 Overview

This project is an **interactive Excel Dashboard** designed to analyze **purchase and shopping trends**.
It provides key insights into **total purchases, product categories, gender preferences, seasonal patterns, purchase frequency, and sizes**.

The dashboard enables quick decision-making by presenting data in a **visually interactive and user-friendly format** with filters for **season, year, and month**.

---

## 🎯 Features

* **KPI Metrics**

  * Total Purchases: **$3,01,055**
  * Accessories: **$94,183**
  * Clothing: **$1,34,688**
  * Footwear: **$48,340**
  * Outerwear: **$23,844**
  * Total Items: **5999**

* **Visual Insights**

  * Purchase by Product (Sweater, Shoes, Pants, Jewelry, etc.)
  * Year-wise Variance (monthly purchase distribution)
  * Purchases by Gender (Male vs Female split)
  * Purchases by Season (Fall, Spring, Summer, Winter)
  * Purchases by Size (L, M, S, XL)
  * Purchases by Frequency (Weekly, Monthly, Quarterly, etc.)

* **Interactive Filters**

  * Season filter (Fall, Spring, Summer, Winter)
  * Year filter (2023, 2024)
  * Month filter (Jan – Oct)

## 🚀 How to Use

1. Download the Excel file from this repository.
2. Open it in **Microsoft Excel (2016 or later recommended)**.
3. Use the **filters (Year, Month, Season)** to explore the data.
4. Analyze insights across **products, gender, frequency, and size**.

---

## 📈 Key Insights

* **Clothing** contributes the highest purchase value (**$1,34,688**).
* **Pants ($14,020)** lead in product sales, followed by sweaters and dresses.
* **Male customers (56%)** purchase more than female customers (44%).
* **Spring season (1,550 items)** sees the highest purchases.
* **Size M (44.02%)** is the most purchased, while **XL (10.84%)** is the least.
